# University Website Assignment

## Project Description
This is a University Website developed as an academic assignment using HTML, CSS, and JavaScript.

The website includes:
- Header and Navigation Menu
- University Departments
- Academic Programs Table
- Admission Inquiry Form
- Footer Section

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Files
- index.html - Main website file
- style.css - Website styling
- script.js - JavaScript functionality
- campus.png - Image file
- lab.png - Image file

## How to Run the Project
1. Download or clone this repository.
2. Extract the project ZIP file if downloaded.
3. Open the project folder.
4. Double-click index.html to open the website in your browser.
